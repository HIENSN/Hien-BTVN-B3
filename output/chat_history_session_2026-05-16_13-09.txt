### Skill 2: Weather API — **kết nối nền tảng bên ngoài** (`.claude/skills/weather-api/skill.md`)

```markdown
---
name: weather-api
description: Lấy thông tin thời tiết từ OpenWeatherMap API và xuất file kết quả
---

Khi người dùng hỏi thời tiết một thành phố:
1. Dùng Bash tool để gọi API: curl "https://api.openweathermap.org/data/2.5/weather?q={city}&appid={API_KEY}&units=metric&lang=vi"
2. Parse kết quả JSON
3. Ghi output vào file output/weather_YYYY-MM-DD.txt theo template trong templates/output_template.txt
4. Báo cáo kết quả cho người dùng
```

File `.claude/skills/weather-api/config.json`:
```json
{
  "api_base_url": "https://api.openweathermap.org/data/2.5",
  "output_dir": "output",
  "units": "metric",
  "lang": "vi"
}
```

File `.claude/skills/weather-api/templates/output_template.txt`:
```

Ngày: {date}
Nhiệt độ: {temp}°C
Mô tả: {description}
Độ ẩm: {humidity}%
========================
```

> **Lưu ý:** Đăng ký API key miễn phí tại [openweathermap.org](https://openweathermap.org/api) (gói Free đủ dùng)

def calc_thue(tnct):
    if tnct <= 0: return 0
    t = min(tnct, 10_000_000) * 0.05

    if tnct > 30_000_000:  t += (min(tnct, 60_000_000)  - 30_000_000)  * 0.20
